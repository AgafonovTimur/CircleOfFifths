# Кварто-квинтовый круг

Приложение для заучивания и проверки выученного кварто-квинтового круга, аккордов на нем и тональностей, а затем проверка ваших знаний


---

## 1. Какие есть функции у приложения

Приложение состоит из **трёх вкладок** вверху экрана:

### Вкладка «Обучение» 
Режим для изучения. Нажимаете на любую ноту на круге — приложение показывает:
- обычные аккорды (мажор/минор), а также Sus2, Sus4 и расширенные аккорды (7, maj7, m7, 9, 11, 13 и их варианты) — всего 20 типов аккордов;
- лады (мажор, минор, дорийский, фригийский, лидийский, миксолидийский, локрийский), а также отдельно гармонический и мелодический минор(у них есть свои условия-написаны в подсказке. сделаны для простоты запоминания)

Ноты аккорда/лада можно показывать двумя способами:
- **Стрелками** — прямо на круге рисуются стрелки от тоники к остальным нотам аккорда/лада;
- **Цветом** — нужные ноты просто подсвечиваются цветом.

Рядом с кругом можно включить мини-клавиатуру пианино(в настройках галочка), которая дублирует те же ноты на клавишных

### Вкладка «Ноты» 
Режим для проверки выученного
- Клик мыши - в центре отображается нота - надо нажать на нее на круге мышью. (для миди пк/миди клавиатуры следующий пункт)
- На пк/миди клавиатуре - нота выделена цветом - надо нажать на клаве пк/миди клавиатуре
- Кнопки мажор и минор просто выбирают все ноты на мажорном и на минорном кольце. 
- Скрыть ячейки круга - отвечать нужно на клавиатуре справа вспоминая именно ноты, а не шаблон
- Кнопка убрать все - оставляет выбранной только ноту C.

### Вкладка «Аккорды/Лады»
То же самое, что «Ноты», но проверяется знание аккордов и ладов: приложение загадывает аккорд или лад, нужно правильно указать все его ноты на круге.

### Общие для всех вкладок функции
- **Подключение MIDI-клавиатуры** — можно подключить MIDI-клавиатуру для ответов.
- **Отправка звука в DAW/приложение** — Работает так же как в тренажере слуха. Есть выбор: сыграть все ноты аккорда одновременно или по очереди, с настраиваемым интервалом и velocity,а также разбить ноты по отдельным MIDI-каналам, если хотите сыграть аккорд например разынми инструментами(одна нота на скрипку, вторая на альт, третья на виолончель. Не divisimate 2, но мало ли пригодится)
- **Подсказки (значок «i»)** — подсказка с объяснением.

## 2. Горячие клавиши

Горячие клавиши работают по физическому расположению клавиши на клавиатуре, поэтому одинаково действуют и на русской, и на английской раскладке.

| Клавиша | Действие |
|---|---|
| **A, B, C, D, E, F, G** | Выбрать ноту на круге. Первое нажатие буквы выбирает её на **мажорном** кольце, повторное нажатие той же буквы — на **минорном** кольце, третье нажатие — снимает выбор. Нажатие другой буквы начинает цикл заново. |
| **Shift + буква** | То же самое, но для диезной ноты (например, Shift+C → C♯). |
| **Пробел, затем буква** | Выбрать бемольную ноту (например, пробел, затем B → B♭). |
| **← / →** (стрелки влево/вправо) | Только во вкладке «Обучение»: поверачивают круг против/по часовой стрелке. |
| **+ / -** | Увеличить/уменьшить масштаб круга. |
| **Shift + -** | Сбросить масштаб круга до 100%. |
| **Q** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение стрелками. |
| **W** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение цветом. |
| **R** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение стрелками. |
| **T** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение цветом. |
| **Y** | Открыть/закрыть панель настроек. |
| **Z** | Во вкладке «Аккорды/Лады»: показать/скрыть подсказку с загаданным аккордом/ладом. |
| **Колесо мыши (прокрутка)** | Во вкладке «Обучение», вне панели настроек: переключает выбранную ноту по кругу — вниз по часовой стрелке, вверх — против.(можно весело покрутить круг колесом мыши+стрелки вправо-влево) |
| **Средняя кнопка мыши (нажатие на колёсико)** | Открыть/закрыть панель настроек (только на компьютере, не на телефоне). |
| цифрами **1–9 и 0** во вкладке «Аккорды/Лады» | переключение между типами аккордов |

Дополнительно во вкладке «Аккорды/Лады» цифрами **1–9 и 0** можно быстро переключаться между типами аккордов, идущими по порядку на экране.

На телефоне: одновременно 2 нажатия открывают/закрывают панель настроек

## 3. Что можно поменять через меню (настройки в интерфейсе)

Все перечисленные пункты находятся в выезжающей панели настроек сбоку от круга (открывается кнопкой Н/Y, свайпом, средней кнопкой мыши).

- **Отображать настройки: Слева / По центру / Справа** — где именно на экране показывать панель настроек.
- **Выбор типа аккорда** — Мажор/Минор, Sus2, Sus4, а также 7, maj7, m7, m(Maj7), add9, m(add9), 9, maj9, m9, m(Maj9), add11, m(add11), 11, maj11, m11, 13, maj13, m13, m(Maj13).
- **Выбор лада** — Лидийский, Мажор, Миксолидийский, Дорийский, Минор, Фригийский, Локрийский, Гармонический минор, Мелодический минор.
- **Вариант отображения — Стрелками / Цветом**, отдельно для «Варианта 1» и «Варианта 2» (двух разных стилей показа стрелок).
- **Показывать буквы аккорда под нотами** — вкл/выкл нот аккорда.
- **Показывать ступени аккорда** — вкл/выкл ступеней аккорда(выбранная нота становится тоникой).
- **Привязать тональность** — фиксирует текущую тональность, чтобы круг не «прыгал» при переключении аккордов/ладов.
- **Показывать клавиатуру** — вкл/выкл клавиатуру мини-пианино рядом с кругом для отображения аккорда.
- **Показать альтернативную ноту на мажорном/минорном кругу** — включает показ энгармонически равной ноты (например, показать A♯ вместо B♭) для отдельных нот круга — можно включить для каждой из 5 «спорных» нот по отдельности.
- **MIDI-настройки**:
  - MIDI вход — ваша миди клавиатура;
  - MIDI выход — куда отправлять звук (например, в DAW);
  - кнопка «Подключить MIDI клавиатуру».
- **Настройки отправки аккорда в DAW**:
  - «Сыграть в DAW (за раз)» — все ноты одновременно;
  - «Сыграть в DAW (по очереди)» — ноты друг за другом;
  - интервал между нотами (в секундах)- если нужно сыграть по отдельности ноты аккорда;
  - Velocity - 0 до 127;
  - формат выхода - midi 1 и midi 2(второй не проверял, работает вроде с windows 11 24H2) ;

## 4. Что можно поменять через настройки внутри файла

Эти настройки нельзя изменить через интерфейс — их правят прямо в тексте HTML-файла (в редакторе кода или даже в блокноте), в самом начале файла, в блоке `<style>`. Все важные места отмечены комментариями на русском прямо в коде.

- **Цвета подсветки на круге** — переменные `--green` (правильный ответ), `--red` (ошибка/замена ноты), `--green-flash`, `--red-flash` (та же подсветка, но с прозрачностью).
- **Цвет подсветки формулы в подсказках (i)** — переменная `--tip-formula-red`.
- **Цвета стрелок-подсказок** во вкладке «Обучение» — `--blue`, `--cyan`, `--yellow`, `--orange`, `--purple`, `--lime`.
- **Цвет колец круга** — `--ring-major` (внешнее, мажорное кольцо), `--ring-minor` (среднее, минорное кольцо), `--ring-note` (кольцо с названиями нот), а также цвета при наведении курсора `--ring-major-hover`, `--ring-minor-hover`.
- **Цвета клавиш мини-пианино** — `--piano-white-key`, `--piano-black-key`, `--piano-key-label-on-white`, `--piano-key-label-on-black`.

Каждая из пяти цветовых тем (Тёмная, Серо-жёлтая, Чёрно-оранжевая, Тёмно-синяя, Светлая) — это свой отдельный набор таких же переменных, поэтому один и тот же цвет можно перенастроить отдельно для каждой темы.
