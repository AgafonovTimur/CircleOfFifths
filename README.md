# Кварто-квинтовый круг / Circle of Fifths  / 五度圈

**Language / Язык / 语言:** [Русский](#русский) | [English](#english) | [中文](#中文)

---

## Русский

### Кварто-квинтовый круг

Приложение для заучивания и проверки выученного кварто-квинтового круга, аккордов на нем и тональностей, а затем проверка ваших знаний

#### 1. Какие есть функции у приложения

Приложение состоит из **трёх вкладок** вверху экрана:

**Вкладка «Обучение»**
Режим для изучения. Нажимаете на любую ноту на круге — приложение показывает:
- обычные аккорды (мажор/минор), а также Sus2, Sus4 и расширенные аккорды (7, maj7, m7, 9, 11, 13 и их варианты) — всего 20 типов аккордов;
- лады (мажор, минор, дорийский, фригийский, лидийский, миксолидийский, локрийский), а также отдельно гармонический и мелодический минор (у них есть свои условия — написаны в подсказке, сделаны для простоты запоминания).

Ноты аккорда/лада можно показывать двумя способами:
- **Стрелками** — прямо на круге рисуются стрелки от тоники к остальным нотам аккорда/лада;
- **Цветом** — нужные ноты просто подсвечиваются цветом.

Рядом с кругом можно включить мини-клавиатуру пианино (в настройках галочка), которая дублирует те же ноты на клавишных.

**Вкладка «Ноты»**
Режим для проверки выученного
- Клик мыши — в центре отображается нота, надо нажать на неё на круге мышью (для миди пк/миди клавиатуры следующий пункт).
- На пк/миди клавиатуре — нота выделена цветом, надо нажать на клаве пк/миди клавиатуре.
- Кнопки мажор и минор просто выбирают все ноты на мажорном и на минорном кольце.
- Скрыть ячейки круга — отвечать нужно на клавиатуре справа, вспоминая именно ноты, а не шаблон.
- Кнопка убрать все — оставляет выбранной только ноту C.

**Вкладка «Аккорды/Лады»**
То же самое, что «Ноты», но проверяется знание аккордов и ладов: приложение загадывает аккорд или лад, нужно правильно указать все его ноты на круге.

**Общие для всех вкладок функции**
- Подключение MIDI-клавиатуры — можно подключить MIDI-клавиатуру для ответов.
- Отправка звука в DAW/приложение — работает так же как в тренажере слуха. Есть выбор: сыграть все ноты аккорда одновременно или по очереди, с настраиваемым интервалом и velocity, а также разбить ноты по отдельным MIDI-каналам, если хотите сыграть аккорд например разными инструментами (одна нота на скрипку, вторая на альт, третья на виолончель. Не divisimate 2, но мало ли пригодится).
- Подсказки (значок «i») — подсказка с объяснением.

#### 2. Горячие клавиши

Горячие клавиши работают по физическому расположению клавиши на клавиатуре, поэтому одинаково действуют и на русской, и на английской раскладке.

| Клавиша | Действие |
|---|---|
| **A, B, C, D, E, F, G** | Выбрать ноту на круге. Первое нажатие буквы выбирает её на **мажорном** кольце, повторное нажатие той же буквы — на **минорном** кольце, третье нажатие — снимает выбор. Нажатие другой буквы начинает цикл заново. |
| **Shift + буква** | То же самое, но для диезной ноты (например, Shift+C → C♯). |
| **Пробел, затем буква** | Выбрать бемольную ноту (например, пробел, затем B → B♭). |
| **← / →** | Только во вкладке «Обучение»: поворачивают круг против/по часовой стрелке. |
| **+ / -** | Увеличить/уменьшить масштаб круга. |
| **Shift + -** | Сбросить масштаб круга до 100%. |
| **Q** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение стрелками. |
| **W** | Во вкладке «Обучение»: переключить «Вариант 1» на отображение цветом. |
| **R** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение стрелками. |
| **T** | Во вкладке «Обучение»: переключить «Вариант 2» на отображение цветом. |
| **Y** | Открыть/закрыть панель настроек. |
| **Z** | Во вкладке «Аккорды/Лады»: показать/скрыть подсказку с загаданным аккордом/ладом. |
| **Колесо мыши** | Во вкладке «Обучение», вне панели настроек: переключает выбранную ноту по кругу — вниз по часовой стрелке, вверх — против. |
| **Средняя кнопка мыши** | Открыть/закрыть панель настроек (только на компьютере). |
| **1–9 и 0** (во вкладке «Аккорды/Лады») | Переключение между типами аккордов, идущими по порядку на экране. |

На телефоне: одновременно 2 нажатия открывают/закрывают панель настроек.

#### 3. Что можно поменять через меню (настройки в интерфейсе)

Все перечисленные пункты находятся в выезжающей панели настроек сбоку от круга (открывается кнопкой Н/Y, свайпом, средней кнопкой мыши).

- Отображать настройки: слева / по центру / справа.
- Выбор типа аккорда — Мажор/Минор, Sus2, Sus4, а также 7, maj7, m7, m(Maj7), add9, m(add9), 9, maj9, m9, m(Maj9), add11, m(add11), 11, maj11, m11, 13, maj13, m13, m(Maj13).
- Выбор лада — Лидийский, Мажор, Миксолидийский, Дорийский, Минор, Фригийский, Локрийский, Гармонический минор, Мелодический минор.
- Вариант отображения — стрелками / цветом, отдельно для «Варианта 1» и «Варианта 2» (двух разных стилей показа стрелок).
- Показывать буквы аккорда под нотами.
- Показывать ступени аккорда (выбранная нота становится тоникой).
- Привязать тональность — фиксирует текущую тональность, чтобы круг не «прыгал» при переключении аккордов/ладов.
- Показывать клавиатуру — мини-пианино рядом с кругом.
- Показать альтернативную ноту на мажорном/минорном кругу — включает показ энгармонически равной ноты (например, A♯ вместо B♭) для 5 «спорных» нот по отдельности.
- MIDI-настройки: MIDI вход, MIDI выход, кнопка «Подключить MIDI клавиатуру».
- Настройки отправки аккорда в DAW: «за раз» (все ноты одновременно) или «по очереди» (ноты друг за другом), интервал между нотами (в секундах), Velocity (0–127), формат выхода — midi 1 и midi 2 (второй не проверял, работает вроде с Windows 11 24H2).

#### 4. Что можно поменять через настройки внутри файла

Эти настройки нельзя изменить через интерфейс — их правят прямо в тексте HTML-файла (в редакторе кода или даже в блокноте), в самом начале файла, в блоке `<style>`. Все важные места отмечены комментариями на русском прямо в коде.

- Цвета подсветки на круге — переменные `--green` (правильный ответ), `--red` (ошибка/замена ноты), `--green-flash`, `--red-flash` (та же подсветка, но с прозрачностью).
- Цвет подсветки формулы в подсказках (i) — переменная `--tip-formula-red`.
- Цвета стрелок-подсказок во вкладке «Обучение» — `--blue`, `--cyan`, `--yellow`, `--orange`, `--purple`, `--lime`.
- Цвет колец круга — `--ring-major` (внешнее, мажорное кольцо), `--ring-minor` (среднее, минорное кольцо), `--ring-note` (кольцо с названиями нот), а также цвета при наведении курсора `--ring-major-hover`, `--ring-minor-hover`.
- Цвета клавиш мини-пианино — `--piano-white-key`, `--piano-black-key`, `--piano-key-label-on-white`, `--piano-key-label-on-black`.

Каждая из пяти цветовых тем (Тёмная, Серо-жёлтая, Чёрно-оранжевая, Тёмно-синяя, Светлая) — это свой отдельный набор таких же переменных, поэтому один и тот же цвет можно перенастроить отдельно для каждой темы.

## English

### Circle of Fifths

An app for learning and testing the circle of fifths, the chords built on it, and keys, with a knowledge check mode.

#### 1. App features

The app has **three tabs** at the top of the screen:

**"Learning" tab**
A study mode. Click any note on the circle — the app shows:
- regular chords (major/minor), as well as Sus2, Sus4 and extended chords (7, maj7, m7, 9, 11, 13 and their variants) — 20 chord types in total;
- modes/scales (major, minor, Dorian, Phrygian, Lydian, Mixolydian, Locrian), plus harmonic and melodic minor separately (they have their own rules, explained in the tooltip, made for easier memorization).

Chord/scale notes can be shown two ways:
- **With arrows** — arrows are drawn on the circle from the tonic to the other notes of the chord/scale;
- **With color** — the needed notes are simply highlighted.

Next to the circle you can enable a mini piano keyboard (checkbox in settings) that mirrors the same notes on keys.

**"Notes" tab**
A mode for testing what you've learned.
- Mouse click — a note is shown in the center, you need to click it on the circle with the mouse (for PC/MIDI keyboard, see the next point).
- On a PC/MIDI keyboard — the note is highlighted, you need to press it on the PC/MIDI keyboard.
- The Major and Minor buttons simply select all notes on the major and minor rings.
- Hide circle cells — you answer using the keyboard on the right, recalling the actual notes instead of the visual pattern.
- The "clear all" button leaves only the note C selected.

**"Chords/Modes" tab**
Same as "Notes", but tests knowledge of chords and modes: the app picks a chord or mode, and you need to correctly mark all its notes on the circle.

**Features shared across all tabs**
- MIDI keyboard connection — you can connect a MIDI keyboard to answer.
- Sending sound to a DAW/app — works the same as in the Ear Trainer app. You can choose to play all chord notes at once or one after another, with adjustable interval and velocity, and split notes across separate MIDI channels if you want to play a chord with different instruments (one note on violin, another on viola, another on cello — not Divisimate 2, but might come in handy).
- Tips (the "i" icon) — an explanatory tooltip.

#### 2. Keyboard shortcuts

Shortcuts work by the physical key position, so they behave the same on both Russian and English keyboard layouts.

| Key | Action |
|---|---|
| **A, B, C, D, E, F, G** | Select a note on the circle. First press selects it on the **major** ring, pressing the same letter again selects it on the **minor** ring, a third press deselects it. Pressing a different letter starts the cycle over. |
| **Shift + letter** | Same, but for the sharp note (e.g., Shift+C → C♯). |
| **Space, then letter** | Select the flat note (e.g., Space, then B → B♭). |
| **← / →** | "Learning" tab only: rotates the circle counter-clockwise/clockwise. |
| **+ / -** | Zoom the circle in/out. |
| **Shift + -** | Reset circle zoom to 100%. |
| **Q** | "Learning" tab: toggle "Option 1" to arrow display. |
| **W** | "Learning" tab: toggle "Option 1" to color display. |
| **R** | "Learning" tab: toggle "Option 2" to arrow display. |
| **T** | "Learning" tab: toggle "Option 2" to color display. |
| **Y** | Open/close the settings panel. |
| **Z** | "Chords/Modes" tab: show/hide the hint with the target chord/mode. |
| **Mouse wheel** | "Learning" tab, outside the settings panel: cycles the selected note around the circle — down for clockwise, up for counter-clockwise. |
| **Middle mouse button** | Open/close the settings panel (desktop only). |
| **1–9 and 0** ("Chords/Modes" tab) | Switches between chord types, in the order shown on screen. |

On mobile: two simultaneous taps open/close the settings panel.

#### 3. What you can change via the menu (in-app settings)

All items below are in the slide-out settings panel next to the circle (opened with the H/Y key, a swipe, or the middle mouse button).

- Settings panel position: left / center / right.
- Chord type selection — Major/Minor, Sus2, Sus4, plus 7, maj7, m7, m(Maj7), add9, m(add9), 9, maj9, m9, m(Maj9), add11, m(add11), 11, maj11, m11, 13, maj13, m13, m(Maj13).
- Mode/scale selection — Lydian, Major, Mixolydian, Dorian, Minor, Phrygian, Locrian, Harmonic minor, Melodic minor.
- Display mode — arrows / color, separately for "Option 1" and "Option 2" (two different arrow styles).
- Show chord letters under the notes.
- Show chord degrees (the selected note becomes the tonic).
- Lock key — fixes the current key so the circle doesn't "jump" when switching chords/modes.
- Show keyboard — a mini piano next to the circle.
- Show alternative note on the major/minor ring — shows the enharmonic equivalent (e.g., A♯ instead of B♭) for each of the 5 "ambiguous" notes individually.
- MIDI settings: MIDI input, MIDI output, "Connect MIDI keyboard" button.
- Chord-to-DAW settings: "Play in DAW (together)" — all notes at once; "Play in DAW (in sequence)" — notes one after another; interval between notes (in seconds); Velocity (0–127); output format — MIDI 1 and MIDI 2 (the latter untested, seems to work on Windows 11 24H2).

#### 4. What can only be changed inside the file

These settings can't be changed through the interface — they're edited directly in the HTML file's text (in a code editor or even Notepad), near the top of the file, in the `<style>` block. All important spots are marked with Russian-language comments in the code.

- Circle highlight colors — variables `--green` (correct answer), `--red` (wrong note), `--green-flash`, `--red-flash` (same highlight but semi-transparent).
- Formula highlight color in tooltips (i) — variable `--tip-formula-red`.
- Hint-arrow colors in the "Learning" tab — `--blue`, `--cyan`, `--yellow`, `--orange`, `--purple`, `--lime`.
- Circle ring colors — `--ring-major` (outer, major ring), `--ring-minor` (middle, minor ring), `--ring-note` (ring with note names), plus hover colors `--ring-major-hover`, `--ring-minor-hover`.
- Mini piano key colors — `--piano-white-key`, `--piano-black-key`, `--piano-key-label-on-white`, `--piano-key-label-on-black`.

Each of the five color themes (Dark, Gray-Yellow, Black-Orange, Dark Blue, Light) is its own separate set of the same variables, so the same color can be reconfigured independently for each theme.

## 中文

### 五度圈

一款用于记忆和检验五度圈、圈上和弦及调性的应用，并附带知识检测功能。

#### 1. 应用功能

应用顶部有**三个标签页**：

**"学习"标签页**
学习模式。点击圈上任意一个音符，应用会显示：
- 普通和弦（大三和弦/小三和弦），以及 Sus2、Sus4 和扩展和弦（7、maj7、m7、9、11、13 及其变体）——共 20 种和弦类型；
- 调式（大调、小调、多利亚、弗里几亚、利底亚、混合利底亚、洛克里亚），以及单独列出的和声小调与旋律小调（它们各有自己的规则，提示中有说明，便于记忆）。

和弦/调式的音符可以用两种方式显示：
- **箭头** —— 在圈上直接画出从主音到和弦/调式其他音符的箭头；
- **颜色** —— 直接用颜色高亮所需的音符。

在圈旁边可以开启迷你钢琴键盘（设置中的复选框），它会在琴键上同步显示相同的音符。

**"音符"标签页**
用于检验所学内容。
- 鼠标点击 —— 中间会显示一个音符，需要用鼠标在圈上点击对应的音符（电脑/MIDI 键盘方式见下一项）。
- 用电脑/MIDI 键盘 —— 音符会被高亮，需要在电脑/MIDI 键盘上按下对应键。
- "大调"和"小调"按钮会分别选中大调环和小调环上的所有音符。
- 隐藏圈上的格子 —— 需要靠右侧键盘作答，凭记忆回想音符本身而非视觉图案。
- "全部清除"按钮只保留音符 C 被选中。

**"和弦/调式"标签页**
与"音符"标签页类似，但检测的是和弦和调式知识：应用会随机出一个和弦或调式，需要在圈上正确标出它的所有音符。

**所有标签页共有的功能**
- 连接 MIDI 键盘 —— 可以连接 MIDI 键盘作答。
- 向 DAW/应用发送声音 —— 与"耳朵训练"应用中的方式相同。可以选择同时演奏和弦的所有音符，或依次演奏（可调节间隔和 velocity），也可以把音符分配到不同的 MIDI 通道，如果想用不同乐器演奏和弦（例如一个音给小提琴，一个给中提琴，一个给大提琴——不是 Divisimate 2，但也许用得上）。
- 提示（"i"图标）—— 带说明的提示。

#### 2. 快捷键

快捷键按物理按键位置生效，因此在俄语和英语键盘布局下效果相同。

| 按键 | 操作 |
|---|---|
| **A, B, C, D, E, F, G** | 在圈上选择音符。第一次按下该字母会选中**大调**环上的音符，再次按下同一字母会选中**小调**环上的音符，第三次按下则取消选择。按下另一个字母会重新开始循环。 |
| **Shift + 字母** | 同上，但用于升号音符（例如 Shift+C → C♯）。 |
| **空格，然后字母** | 选择降号音符（例如空格后按 B → B♭）。 |
| **← / →** | 仅在"学习"标签页：逆时针/顺时针旋转圆圈。 |
| **+ / -** | 放大/缩小圆圈。 |
| **Shift + -** | 将圆圈缩放重置为 100%。 |
| **Q** | "学习"标签页：将"方案 1"切换为箭头显示。 |
| **W** | "学习"标签页：将"方案 1"切换为颜色显示。 |
| **R** | "学习"标签页：将"方案 2"切换为箭头显示。 |
| **T** | "学习"标签页：将"方案 2"切换为颜色显示。 |
| **Y** | 打开/关闭设置面板。 |
| **Z** | "和弦/调式"标签页：显示/隐藏当前题目和弦或调式的提示。 |
| **鼠标滚轮** | "学习"标签页，设置面板之外：沿圆圈切换选中的音符——向下滚动为顺时针，向上滚动为逆时针。 |
| **鼠标中键** | 打开/关闭设置面板（仅限电脑）。 |
| **1–9 和 0**（"和弦/调式"标签页） | 按屏幕上显示的顺序切换和弦类型。 |

手机上：同时两指点击可打开/关闭设置面板。

#### 3. 通过菜单可更改的内容（应用内设置）

以下所有项目都在圆圈旁边的滑出式设置面板中（可通过 H/Y 键、滑动手势或鼠标中键打开）。

- 设置面板位置：左 / 居中 / 右。
- 和弦类型选择——大调/小调、Sus2、Sus4，以及 7、maj7、m7、m(Maj7)、add9、m(add9)、9、maj9、m9、m(Maj9)、add11、m(add11)、11、maj11、m11、13、maj13、m13、m(Maj13)。
- 调式选择——利底亚、大调、混合利底亚、多利亚、小调、弗里几亚、洛克里亚、和声小调、旋律小调。
- 显示方式——箭头 / 颜色，"方案 1"和"方案 2"（两种不同箭头风格）分别设置。
- 在音符下方显示和弦字母。
- 显示和弦级数（所选音符成为主音）。
- 锁定调性——固定当前调性，使圆圈在切换和弦/调式时不会"跳动"。
- 显示键盘——圆圈旁边的迷你钢琴。
- 在大调/小调环上显示替代音符——对 5 个"有争议"的音符分别开启等音异名显示（例如显示 A♯ 而非 B♭）。
- MIDI 设置：MIDI 输入、MIDI 输出、"连接 MIDI 键盘"按钮。
- 向 DAW 发送和弦的设置："同时演奏"（所有音符一起）或"依次演奏"（音符先后进行）、音符间隔（秒）、Velocity（0–127）、输出格式——MIDI 1 和 MIDI 2（后者未充分测试，在 Windows 11 24H2 上似乎可用）。

#### 4. 只能通过文件内部设置更改的内容

这些设置无法通过界面更改——需要直接在 HTML 文件文本中修改（用代码编辑器甚至记事本），位置在文件开头的 `<style>` 代码块中。代码中所有重要位置都有俄语注释标注。

- 圆圈高亮颜色——变量 `--green`（正确答案）、`--red`（错误/替换的音符）、`--green-flash`、`--red-flash`（相同高亮但带透明度）。
- 提示（i）中公式的高亮颜色——变量 `--tip-formula-red`。
- "学习"标签页中提示箭头的颜色——`--blue`、`--cyan`、`--yellow`、`--orange`、`--purple`、`--lime`。
- 圆圈环的颜色——`--ring-major`（外环，大调环）、`--ring-minor`（中环，小调环）、`--ring-note`（音符名称环），以及鼠标悬停颜色 `--ring-major-hover`、`--ring-minor-hover`。
- 迷你钢琴琴键颜色——`--piano-white-key`、`--piano-black-key`、`--piano-key-label-on-white`、`--piano-key-label-on-black`。

五种配色主题（深色、灰黄色、黑橙色、深蓝色、浅色）各自拥有一套相同的变量，因此同一种颜色可以针对每个主题单独重新配置。
