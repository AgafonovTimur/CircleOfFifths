# Circle of Fifths Trainer

Однофайловый HTML-тренажёр для тренировки узнавания аккордов на круге квинт. Приложение показывает название аккорда в центре круга, а пользователь должен кликнуть по соответствующему сегменту (мажор / минор / уменьшённый).

Открывается прямо в браузере — никаких зависимостей, сборки или сервера не требуется.

## Что умеет

- **Круг квинт из трёх колец**: внешнее — мажорные трезвучия, среднее — минорные, внутреннее — уменьшённые (dim).
- **Викторина**: в центре круга загадывается случайный аккорд (текстом), нужно кликнуть по нужному сегменту.
  - Правильный клик — сегмент подсвечивается зелёным.
  - Неправильный клик — выбранный сегмент подсвечивается красным, а правильный — зелёным.
  - После клика автоматически загадывается следующий аккорд (тот же аккорд подряд не повторяется, если выбрано больше одного).
- **Выбор аккордов для тренировки**: отдельное меню (открывается клавишей `Y`/`Н`) с собственным кругом, где можно кликами включать/выключать конкретные аккорды, а также включать/выключать сразу всё кольцо кнопками «Мажор», «Минор», «Dim». Кнопка «Убрать все» сбрасывает выбор до одного аккорда — до мажорного C.
  - Выбор сохраняется в `localStorage`, поэтому сохраняется между перезапусками страницы.
  - Нельзя снять выбор с последнего оставшегося аккорда — минимум один должен быть активен.
- **Масштабирование круга**: клавиши `+`/`-` увеличивают/уменьшают круг (от 100% до 1000%, шаг 10%). Масштаб сохраняется в `localStorage`.

## Горячие клавиши

| Клавиша | Действие |
|---|---|
| `+` / `=` | Увеличить масштаб круга |
| `-` / `_` | Уменьшить масштаб круга |
| `Shift` + `-` | Сбросить масштаб к 100% |
| `Y` / `Н` | Открыть/закрыть меню выбора аккордов |

## Что можно поменять в самом файле

Все основные настройки вынесены в именованные константы/объекты в начале `<script>` и в CSS-переменные `:root`, чтобы не искать значения по всему коду.

### Цвета (`:root` в `<style>`)
```css
--bg: #1a1a1a;              /* цвет фона страницы и центрального круга */
--shadow: #303030;
--text: #8e8e8e;             /* цвет текста интерфейса */

--ring-major: #404040;       /* цвет кольца мажорных аккордов */
--ring-minor: #404040;       /* цвет кольца минорных аккордов */
--ring-dim: #404040;         /* цвет кольца уменьшённых аккордов */
--ring-major-hover: #474747;
--ring-minor-hover: #3c3c3c;
--ring-dim-hover: #333333;

--green: #b3ffb3;            /* цвет "правильно" */
--red: #ffcccc;              /* цвет "неправильно" */
--green-flash: rgba(179,255,179,0.5); /* вспышка правильного ответа */
--red-flash: rgba(255,204,204,0.5);   /* вспышка неправильного ответа */
```

### Буква/аккорд в центре круга (`CENTER_NOTE_CONFIG`)
```js
const CENTER_NOTE_CONFIG = {
  fontSize: 47,          // размер шрифта
  color: "#8E8E8E",      // цвет текста
  fontFamily: "Arial, Helvetica, sans-serif",
  verticalOffset: 0.36   // тонкая настройка вертикального центрирования (в em)
};
```
`verticalOffset` нужен для точной подгонки буквы по центру круга: увеличьте значение, если буква выглядит выше центра, уменьшите — если ниже. Это связано с тем, что вертикальное центрирование текста через `dominant-baseline` в SVG работает немного по-разному в разных браузерах и шрифтах, поэтому добавлена ручная компенсация.

### Геометрия круга
```js
const CX = 240, CY = 240;   // центр SVG-круга

const R0 = 55;    // радиус пустого центра (где отображается аккорд)
const R1 = 95;    // внешний радиус кольца "уменьшённые"
const R2 = 160;   // внешний радиус кольца "минор"
const R3 = 235;   // внешний радиус кольца "мажор"

const WEDGE_GAP_RADIAL = 1;   // зазор между кольцами, px
const WEDGE_GAP_ANGLE  = 0.5; // зазор между сегментами внутри кольца, град.
```

### Список аккордов по кольцам
```js
const majors = ['C','G','D','A','E','B','F#','Db','Ab','Eb','Bb','F'];
const minors = ['Am','Em','Bm','F#m','C#m','G#m','D#m','Bbm','Fm','Cm','Gm','Dm'];
const dims   = ['B°','F#°','C#°','G#°','D#°','A#°','F°','C°','G°','D#°','A°','E°'];
```
Порядок в массивах соответствует положению сегментов на круге по часовой стрелке, начиная сверху (12 часов).

### Масштабирование
```js
const ZOOM_MIN = 100;   // минимальный масштаб, %
const ZOOM_MAX = 1000;  // максимальный масштаб, %
const ZOOM_STEP = 10;   // шаг изменения масштаба, %
```

### Хранение данных
Приложение использует `localStorage` для двух вещей:
- `circleSelectedNotes` — какие аккорды включены в тренировку;
- `circleOfFifthsZoom` — текущий уровень масштаба.

Чтобы сбросить всё к настройкам по умолчанию, достаточно очистить `localStorage` для этой страницы (например, через DevTools → Application → Local Storage) или вручную удалить эти два ключа.

## Структура файла

Всё содержится в одном HTML-файле:
- `<style>` — оформление и CSS-переменные цветов;
- разметка (`#app`, `#circleWrap`, `#menuOverlay`) — игровой круг и модальное окно выбора аккордов;
- `<script>` — вся логика: построение SVG-колец, викторина, меню выбора нот, масштабирование, обработка клавиш.
